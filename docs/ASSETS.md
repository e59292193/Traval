# 素材与授权清单

V0.2 的完整来源、实际审图号、处理方法和使用限制，见 [地图与视觉素材说明](MAP-AND-ART.md)。

| 内容 | 来源 | 当前使用 / 边界 |
| --- | --- | --- |
| 中国地图（含台湾、海南与南海诸岛附图） | 西部网文章公开 PDF；图内 GS(2016)2923号 | 本地静态图，整体缩放、白底透明化、保留附图白底。最终拼贴未经重新审图；公开/商用前核实 |
| 手账水彩纸张、相机、罗盘、企鹅、露营车等 | 开发阶段 AI 预生成插画 | 仅静态底板，不含 AI 地图、用户数据或虚构统计；商业许可边界需核实 |
| 8 枚冰箱贴插画 | 开发阶段 AI 预生成 | 本地透明图集，非用户真实收藏，也不宣称用户去过这些地点 |
| 4 张可选示例照片 | AI 生成虚构旅行场景 | 必须带示例标记；不是用户照片或地理定位；可清空 |
| Caveat 拉丁手写字体子集 | Google Fonts / Caveat Project Authors | SIL OFL 1.1；原许可随仓库提供；中文和缺字用系统回退 |
| 用户照片 | 用户设备选择 | 本地合成；使用者须有权使用，不读取 GPS、不上传 |
| 用户上传参考图 | 原作者与许可待确认 | 用作构图参考，不直接当作输出海报背景；不能据此宣称第三方权利已清理 |
| npm 依赖 | 各开源包作者 | 各自许可保留；依赖安全问题仍为发布阻塞项 |

本项目代码/版式没有擅自指定全仓库 MIT 等对外许可；由负责人决定。AI 预制素材、地图和字体的使用要求需分别判断。
