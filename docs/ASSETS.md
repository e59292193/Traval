# 素材与授权清单

| 素材/组件 | 来源与作者 | 修改/使用方式 | 授权与商业发布状态 |
| --- | --- | --- | --- |
| 「单次旅行纪念」版式 | 本项目新编写的原创布局代码 | 四相框、标题区、页脚 | 未复制参考图整套版式；最终对外代码/设计许可由项目负责人决定 |
| 纸色、微纹理、胶带、相框、叶片、路线、ON THE ROAD 邮戳 | 本项目 Canvas 几何绘制 | 没有外部图片文件或品牌商标 | 无外部素材采购；原创代码/设计许可同上，不构成法律合规保证 |
| UI 图标 | 系统文字字符 ↗ / ＋ / ✓ 等 | 系统字体显示 | 未分发第三方图标包；依赖终端系统字体 |
| 中文和英文字体 | 终端系统字体回退栈 | 不打包、不下载字体文件 | 不宣称拥有第三方字体文件再分发权；商用终端/品牌字体政策需发布前核实 |
| 用户照片 | 用户设备自行选择 | 内存解码裁剪，设备本地合成 | 使用者需有权使用；应用不对照片内容的著作权作保证 |
| E2E 合成测试图 | 测试脚本生成色带、渐变、QA 标识 | 仅验证比例、方向和导出 | 测试图不是内置示例，不冒充真实旅行照，不用于宣传样张 |
| 用户提供的参考图 | 用户提供，原作者和许可证未知 | 仅理解温暖复古、拍立得拼贴风格；未纳入仓库或裁切复用 | 待确认；不进入商业发布资产 |
| npm 开源依赖 | 各包作者 | 构建/运行框架及测试工具 | 保留各自 LICENSE；商业发布前做完整 SBOM、许可和安全复核 |

没有使用预制 AI 图片、在线生图服务、地图底图或外链照片。不要将「没有调用生图 API」理解为所有内容自动获得商业授权。

本仓库暂不添加统一 MIT/Apache 等许可证，以免未经负责人确认扩大授权。若决定对外开源，需要先选定项目许可证并核查第三方义务。
