# V0.3 足迹地图、旅行记录与本地草稿

## 实现范围

H5：地图缩放/拖动/复位、地区点击与列表标记、城市点选查看、370个地点预设及自定义坐标、旅行与地点增删改、列表顺序连线、多旅行筛选、实际记录去重统计、照片版本关联、IndexedDB手动草稿、固定全国范围手账合成导出。原静态拼贴仍可用。

没有道路瓦片、地理编码、GPS、云同步、登录或付费。地图上的真实足迹点与旧版装饰照片分开；开启足迹合成后主地图不再盖装饰相框，以免误认为相框位置就是地点。最近回忆保留四个槽位。地图点支持显示相关照片，照片添加关联时保存稳定资源ID；之后替换手账槽位不改写历史照片，但这不是云相册。

## 记录规则

- Trip可以为空，旅行数计已创建的记录条数，不自动声称实际出行已完成。
- City/Place按稳定id去重；预设省级中心采用已有兼容id，自定义地点id包含地区、名字和坐标。将同一实际城市以不同自定义名字创建会被计为不同地点，因此UI使用“地点/城市”，不是权威城市足迹认证。
- 地区统计合并所有地点地区与手动标记；地图旅行筛选只筛选地点/路线，手动地区标记始终保留。海报统计注明全部旅行，地图注明当前筛选。
- 日期可留空；非空必须是真实日历日期YYYY-MM-DD。路线按列表顺序而非自动日期排序，允许多次到同一地点；连线不是实际道路或导航。
- 不同Trip之间不连线。同一地图的重复地点只显示一个标记，所有到访记录仍保留在时间线。
- AI示例照片不生成记录，新建/编辑关联时拒绝直接关联AI示例。关联时保留照片资源版本，后续替换槽位不改写历史；不以照片作为自动验证旅行真实性的证据。

## 本地草稿

- 数据库`traval-local-v1`，store `draft`，key `current`；单个最新草稿，手动保存、手动恢复，不自动覆盖现有编辑，不自动迁移未知版本。
- Work v2 + Journal v1 + savedAt + 当前手账及历史关联照片的JPEG Blob（最多32张），单次原子事务，连同历史记录引用的照片版本一起保存。照片源为编辑器已降采样结果，重新编码JPEG质量0.92，照片总编码容量限制30MB；不是保留相机原文件/元数据。
- 不在localStorage放Base64，不跨浏览器/域名/设备同步；浏览器配额、隐私模式、同源权限和清理行为会影响存储，不能保证永久保存。
- 读取先校验版本/字段/照片绑定，再全部解码成功后替换当前编辑；保存配额失败、解码失败或不兼容数据不会主动清空当前内容。
- 删除已保存草稿保留当前编辑；重置编辑器会清空当前手账/旅行，但不删除已保存草稿；整次旅行或地点删除需确认。

## 小程序

仍只提供静态手账。旅行纯数据模型可复用，地图组件和文件存储需另做平台适配与真机验证；不承诺零修改迁移。
