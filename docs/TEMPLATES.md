# 地图手账模板（V0.2）

唯一活动模板：`src/templates/journey.ts`，ID `china-scrapbook`，模板版本 `2`，作品数据版本 `2`。

## 版式

逻辑画布 1000×1340；预览栅格 900×1206；默认 JPEG 1500×2010，轻量 1000×1340。接近参考图的纵向比例，不再使用旧版四宫格 1000×1400。

顺序为：本地水彩底板 → 可编辑手写标题 → 静态中国地图 → 手账纸页文字/卡片 → 地图上的四个拍立得照片。下方最近回忆会复用同四张照片，不增加照片槽位或产生虚假旅行记录。

## 修改方法

- 保持图层 ID、位置、尺寸、角度、透明度可 JSON 序列化。
- 四个 binding 固定 `p1`–`p4`，对应作品 `photos` 和 `captions`。
- 图片素材通过稳定 ID 解析到单独的 assets Map，不把 object URL 写入模板。
- 照片边距与标题区使用图层配置 `padding`、`captionHeight`、`captionSize`，通过 `core/photo-box.ts` 统一计算。渲染与拖动必须使用同一个 photoBox。
- 手账底板和文字排版辅助逻辑在 `render/poster.ts`。菜单、搜索框、路线属于导出纸面装饰，不是新增真实搜索/导航功能。
- `work.text` 包含标题、寄语、日期、昵称、札记、心愿；`captions` 独立存每张照片的标题和可选日期。
- 示例标记跟随每个照片绑定；不能在仍有示例照片时隐藏说明。

## 地图安全边界

不手绘、更改或 AI 补全边界，不裁掉台湾或南海诸岛附图。固定照片位置只是排版，不是坐标映射，不能据此宣称用户去过对应省份。改变地图来源、比例、标点或公开用途后，需重新核实 MAP-AND-ART.md 中的审图/授权事项。

V0.1 没有持久化作品，因此本次没有伪造旧草稿自动迁移功能。未来加入草稿持久化时，必须按 templateId/templateVersion/dataVersion 做显式迁移和回归。
