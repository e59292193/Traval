# 模板说明

当前唯一模板位于 `src/templates/journey.ts`，ID `one-journey`，版本 `1`。模板必须能通过 JSON 往返序列化。

## 修改步骤

1. 调整 `journey` 的图层坐标、配色或字段配置。
2. 保持逻辑尺寸和槽位 binding 的含义明确；四个照片槽位当前绑定 `p1`–`p4`。
3. 每个图层必须有唯一 ID、位置、尺寸、角度、透明度。
4. 文字配置指定字段、字号、最小字号、字重、颜色角色、对齐、行高、最大行数和溢出策略。画布字体测量与绘制始终相同。
5. 照片图层的宽/高包含相框：左右各 16，上侧 16，下方留白共 59；实际照片区域为 `width - 32` × `height - 75`。修改边距应同步修改渲染器和拖动映射并增加测试。
6. 新增静态图片素材需使用稳定资产 ID，由资源解析器/预加载过程注册到运行时 Map，不能在模板里写 blob URL、用户临时路径或浏览器对象。
7. 执行 `npm test`、`npm run typecheck`、双端构建、`npm run test:e2e`，实际查看导出 JPEG。

## 版本策略

- 仅配色/装饰的兼容变化可以保留模板版本，但须记录变更。
- 槽位语义、字段绑定、尺寸或裁剪含义变化时应升模板版本。
- 作品同时记录 templateId、templateVersion 和 dataVersion。
- 本阶段没有持久化旧作品，所以没有伪造「全版本自动迁移」能力；加入草稿时需要显式迁移函数及旧数据回归测试。

## 后续模板

年度旅行足迹、情侣/好友模板不在本次实现范围。真实地图不是简单的一张背景图：必须先明确地区范围、合规底图、授权、坐标系和经纬度映射，再确认实现。首版不会因参考图有地图、统计和侧栏而添加虚构功能。
