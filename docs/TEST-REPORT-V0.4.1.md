# V0.4.1 实测记录

## 结果

- 37/37 核心测试通过。
- 66 项浏览器检查通过：真实 MapLibre/Worker 专项 11、实际应用旅行闭环 24、旧草稿/断网异常专项 6、照片原有功能 25。
- TypeScript 检查、H5 production 构建、微信小程序静态手账构建通过。
- 图层专项未发现未捕获异常或 MapLibre 错误；记录在 `docs/evidence/v041/renderer.json`。

## 新增验证

- 真正查询 MapLibre Worker 中的 GeoJSON：三地点两段线、关闭后零段、重排后的起终点、切换单点旅行清除旧路线、全部旅行不跨旅行连接、16次快速开关最后状态一致。
- 实际点击地图四川区域：点亮/取消，不虚构城市或旅行。
- 同时使用手动地区和当前旅行地区，检查填色源；只修改手动地区也使导出缓存失效。
- 地图点选优先于地区点击，不误点亮；实际应用界面开关和手动地区取消/重亮另有回归。
- “台湾省”共享样式表达式的单元测试、真实台湾要素显示与截图检查，不误改台湾海峡和城市名。
- 同一个离屏导出实例，关闭连线后等待 Worker 更新，导出数据源确认为零段；不是只比较页面开关。
- 街区缩放、聚合、旧坐标保护、历史照片、IndexedDB 恢复/配额/损坏、强制失败、窄屏及断网静态回退继续回归。

## 环境和视觉检查

Linux、Node 24.22.1、Playwright + Chromium；WebGL 在沙箱使用 SwiftShader。实际应用基于 production build；独立图层专项用隔离 Vite 测试入口（仅 tests，未进入生产构建）。使用合成照片，不含用户照片。

检查桌面应用、地图控制区、地区填色与路线、台湾省标注、移动端控制区与地图、路线开/关的导出、全国填色导出与实际海报地图区域。截图和生成图片仅保存在本次本地 `artifacts/v041/`，不提交二进制测试素材。

## 仍未代表完成

- 没有验证 Render 公网部署结果；需实际网站刷新到 v0.4.1。
- 没有完成 iOS/Safari/Android/微信真机、手机内存/GPU与大数据压力测试；小程序构建不等于 MapLibre 小程序适配。
- 地区覆盖是简化的 Natural Earth 概览层，与精细底图存在边界/海岸差异，不用于精确行政归属。公开发布与审图要求仍需核实。
- 没有自动转换旧坐标、道路导航、在线地址检索或云同步。原有依赖安全审计风险不因本次修复而消失。
