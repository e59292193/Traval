# 微信小程序迁移与验证清单

## 已实际完成

- uni-app 的 mp-weixin 目标已成功编译；输出 `dist/build/mp-weixin`。
- 小程序适配使用 Canvas 2D 节点 `node.getContext('2d')`，不是把浏览器 API 直接搬过去。
- 实现 `uni.chooseImage`、`getImageInfo`、节点 `createImage`、`canvasToTempFilePath` 与 `saveImageToPhotosAlbum` 的代码路径。
- 取消选图、格式/尺寸限制、导出失败、相册拒权/取消具备可恢复提示分支（这些分支目前仅代码检查，未真机实测）。

**上面只有构建有实际运行证据；不代表这些运行时 API 已在开发者工具或真机通过。** 当前环境是 Linux，没有微信开发者工具或手机相册权限环境。

## 可直接复用

`types/`、`templates/`、`core/`、绘图顺序及文本/裁剪计算。Vue 表单、照片槽位和滑杆通过 uni 组件编译。H5 DOM/Bitmap/下载实现通过条件编译排除。

## 开始验证

1. 在微信公众平台准备自己的小程序 AppID，不在聊天中发送 AppSecret，也不写入前端。
2. 在 `src/manifest.json` 的 `mp-weixin.appid` 填写 AppID（AppID 是公开标识，不是 AppSecret）；如项目成员权限不够，先完成授权。
3. `npm ci && npm run build:mp-weixin`。
4. 用微信开发者工具导入 `dist/build/mp-weixin`；先在基础库 3.7.12 或更高兼容版本验证 Canvas 2D 节点。
5. 用至少一台 iPhone 和一台 Android 实机按下表逐项记录。
