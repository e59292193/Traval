## 内存短周期采样

采样方法：通过 Chromium CDP 执行 HeapProfiler.collectGarbage，读取 Performance 的 JSHeapUsedSize 及 DOM counters。测试中每轮释放旧照片和旧导出结果。浏览器进程仍有图像解码、GPU、原生 bitmap 等不包含在这些指标中的内存。

| 指标 | 10 次循环前 | 10 次循环后 |
| --- | ---: | ---: |
| JS heap used（bytes） | 5438672 | 5654288 |
| documents | 1 | 1 |
| DOM nodes | 1070 | 1219 |
| JS event listeners | 377 | 412 |

这里只记录观察值，不下「绝对无内存泄漏」结论。后续须在低内存手机上长时间重复、多批次测量并检查 bitmap/GPU/进程内存是否持续增长。

## 图片方向与资源准备

Chromium 下实际构造并选择带 EXIF orientation=6 的 JPEG，缩略图方向为竖向；没有再次手动旋转。其他 EXIF 方向、Safari、微信节点解码方向尚未全部验证。系统字体不下载字体文件；强制准备失败时可见提示并继续系统字体回退。

## 本次发现并修复

1. cover 裁剪在极端比例下的浮点数产生微小负边界：将源裁剪宽高夹紧到源图尺寸，回归通过。
2. uni-input 超长输入后内部原生值回写不同步：先接收原生值、下一 tick 回写 grapheme 限长值，并使用真实输入框验证。
3. uni-app 默认预加载外链导航阴影：移除未使用阴影 URL、禁用预加载；最终网络检查通过。
4. 字体回退提示会被导出成功提示快速覆盖：将警告保留在导出弹层说明中，并增加强制失败回归。
