## 25 项浏览器检查覆盖

- 四个初始空槽位、日期默认空白。
- 横、竖、方、宽幅图及 JPEG/PNG/WebP。
- 每张照片真实滑杆缩放，第一张的水平位置与指针拖动。
- 三套配色切换保留文字和照片。
- 高清/轻量 JPEG、桌面下载、预览和导出对比。
- 中文、英文、emoji、24 字标题边界。
- 移除、重选及串行连续替换，保留其他槽位。
- 取消选择、HEIC、15MB、超像素、损坏文件及恢复。
- EXIF orientation 6（Chromium）不重复旋转。
- 强制导出失败后恢复；强制字体准备失败后保留可见警告。
- 10 次换图→导出→关闭短周期采样。
- 390px 无水平溢出，裁剪/导出/重置/确认可操作。
- 示例显式加载、四张缩略图实际可解码、逐张示例标记和示例导出确认。
- 替换一张只移除其示例标记；清空全示例无需再次确认，保留文字和地图；有用户照片时先确认。
- 照片标签、昵称、札记和心愿可编辑。
- 首次模板素材强制解码失败时显示重新准备入口，重试恢复且只保留一个预览 Canvas。
- 本地正式构建没有外部请求、上传或运行时错误。

## 实际发现并修复的视觉问题

1. 标题被换行成孤立的字母：改为单行适配，并内嵌附 OFL 许可的 Caveat 拉丁手写字体。
2. 最近回忆照片标签压在图像上：统一 photoBox 和标题区计算。
3. 冰箱贴背景呈矩形：按单元格连通背景去底，保留模切白边。
4. 装饰透入南海诸岛附图：保留附图原白底，且不在台湾/附图上叠照片。
5. 示例照片在编辑区缩略图为空：让本地素材解码同时返回有效预览来源，并加入图片实际解码断言。
6. 部分装饰符号缺字：换为常用图形或 Canvas 线条图标。
