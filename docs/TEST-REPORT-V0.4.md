# V0.4 实测报告

## 环境和范围

Linux、Node 24.22.1、production H5 构建、本机静态服务、Playwright + Chromium。地图测试在沙箱使用软件 WebGL（SwiftShader）；不等于真实手机 GPU/网络性能。使用合成测试图片，不包含用户照片。以下结果不是商业发布、安全、审图或真机验收结论。

证据：`docs/evidence/v4/`，测试脚本 `tests/e2e.mjs` / `tests/travel-e2e.mjs` / `tests/map-v4-e2e.mjs`。完整网络请求/截图/JPEG仅在本次本地 `artifacts/` 保存，不提交用户照片或生成图片到 GitHub。

## 限制与阻塞

- Safari/iOS、Android/微信 WebView、真实手机内存和 GPU、EXIF 全方向均未完整验证。
- 未做大规模旅行/聚合性能验收；代码输入上限不是设备容量承诺。
- 远程瓦片无可用性保证，大陆网络与数据更新仍需用户实际测试；不是离线冷启动应用。
- 地图边界、数据/样式署名、许可和中国地图公开发布要求仍需专业核实；不能沿用静态图审图号。
- 依赖审计：41 项（6 low、10 moderate、25 high、0 critical），未强制升级，仍阻塞商业发布。快照见 `docs/evidence/npm-audit-v0.4-production.json`。
- 本次推送 GitHub 源码不等于已验证 Render 公网部署。自动部署是否成功、原域名草稿是否可恢复，需要在实际网站确认。
