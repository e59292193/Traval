# V0.4.3 本地异形冰箱贴验证

## 结果

- 类型检查、H5 构建、小程序构建均通过。
- 单元测试 53 / 53：原有 43 项，加上 10 项本地蒙版、风格化、轮廓与原图引用校验。
- 实际浏览器检查 77 项通过：本地异形 20、旧版冰箱贴兼容 8、照片 25、旅行/草稿/地图回归 24。
- 无新增依赖。照片未上传，无模型下载，无第三方图像服务。

## 本地异形实际浏览器覆盖（20）

1. 新上传默认异形主体流程，非方形/圆形相框。
2. 真实 Worker 自动去除边缘连通背景，输出带透明通道和轮廓白边的 PNG。
3. 未加入的原图和处理结果不写入草稿。
4. 未分离背景的整张图片禁止生成；撤销恢复蒙版。
5. 点选背景与撤销更新实际蒙版。
6. 鼠标拖动擦除、坐标落点补回可用。
7. 加入后原图与 PNG 结果分别保存。
8. 取消重新编辑保留原配方与原效果。
9. IndexedDB 恢复后透明角仍为 alpha 0，不变成白色矩形。
10. 对仓库演示山景进行实际多边形圈选并生成不规则透明贴。
11. 390px 编辑工具、滑杆、预览无横向溢出。
12. 页面/Worker 已加载后，断网仍可重新生成。
13. 原图、手动轮廓与参数持久化。
14. 重复生成并保存后，旧处理结果释放，源图数量不增长。
15. 实际 1500×2010 手账输出包含透明异形贴、无固定相框。
16. 移除释放不再引用的原图和结果。
17. 特别高的竖图编辑区域保持在 360 CSS 像素内。
18. 强制 Worker 构造失败后提示错误，可重试、生成和取消，不损坏已加入作品。
19. 损坏上传不会清空贴纸集合或留下半初始化编辑器。
20. 请求检查无照片 POST、模型下载或第三方图像服务，无未捕获运行异常。

## 视觉检查与演示说明

查看桌面和 390px 编辑器实际截图、真实透明 PNG、1500×2010 海报以及原图/结果对比。确认编辑控件不重叠，手机无页面横向溢出；白边沿不规则蒙版，透明区域可透出软木板；无新增方/圆相框。复杂照片展示使用手动轮廓，自动算法误删风险在界面说明，未宣称自动语义识别或参考图一比一复制。

演示山景是仓库已有 AI 示例素材，不是用户照片、真实旅行证据，也不是本次调用 AI 新生成的结果。算法技术夹具只用于确定性测试，不作为插画视觉交付。
