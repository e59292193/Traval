# V0.4.1 地图标注、点亮与连线修复

## 改动

- 精细底图中“台湾 / 臺灣 / 台灣 / Taiwan”对应地名统一显示“台湾省”；交互地图与海报导出共用同一个样式函数。不做全局字符串替换，避免把“台湾海峡”和城市名误改。
- 补上独立的地区点亮填色层。开启“地区点亮”时，可点击地图省级区域点亮/取消；列表仍可操作。地图选点模式优先，不再把选坐标误作地区点亮。
- 手动地区标记对全部旅行生效；从到访记录推导的填色跟随当前旅行筛选。已有到访记录的地区不因点击取消而丢失记录，也不再偷偷增加手动标记；界面会解释需要编辑/删除对应记录。
- 修复异步图层更新：MapLibre 6 的 `GeoJSONSource.setData()` 返回 Promise，现等待 Worker 更新完成；快速切换会继续处理最新状态，捕获异步错误，更新聚合点配色。传入 Worker 的数据是普通快照，不保留 Vue 代理或可变坐标引用。
- 导出缓存键包含地区点亮状态；修改地区、连线开关、顺序、旅行筛选后使用最新数据。海报导出等待数据与瓦片，不只等待界面开关。
- 连线不跨旅行，不越过未核验旧坐标，不生成同坐标的零长度线。新增“有效地点 / 连线段数 / 已隐藏”提示。点亮地区不虚构城市或路线。
- 切换旅行/删除地点清理失效的详情选择；列表查看地点会定位到该地点；选取新坐标会清理上一条记录编辑状态。

## 使用说明

1. 仅记录“去过某省”：开启“地区点亮”，点击地图区域，或打开“标记去过的地区”。不需要新建旅行，也不会生成城市足迹或连线。全国概览最适合查看地区填色。
2. 记录城市与路线：新建旅行 → 添加至少两个不同坐标的已核验地点 → 打开“显示地点顺序连线”。顺序按时间线排列，可上移/下移，不按日期自动排序。
3. 旧坐标仍需明确核验后才绘制地点/连线。原地区归属可以参与地区概览，不代表原坐标已经被转换。
4. 地图选点与地区点亮是不同模式；进入选点会关闭地区点击点亮，以免误操作。
5. 海报范围由“海报地图范围”选择；交互地图拖动视窗不是最终海报范围。选择全国概览可在成品中查看远处手动点亮的地区。
6. 保存本地草稿仍是手动操作；本次不清空已有草稿或照片。

## 地区覆盖层来源与边界

- Natural Earth 1:10m Admin-1：
  https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_10m_admin_1_states_provinces.geojson
- 原始文件 SHA256：`22d0e3ad85eb3e27f17cabf8ba2d50e554fbc27a87796ff891d958185da62fb5`。
- 按应用现有 34 个地区 ID 聚合 72 条来源要素；简化容差 0.008 度，坐标保留4位小数。重建脚本 `scripts/build-region-overlay.py`，输入本地原始文件，不在应用运行时下载原始数据。
- Natural Earth 数据为 public domain，条款：https://www.naturalearthdata.com/about/terms-of-use/ 。本地文件 `src/data/region-overlay-wgs84.json` 使用 WGS84 经纬度；没有把旧 DataV 坐标冒充 WGS84。
- **这是概览级浅色覆盖，不是精确行政边界**。不同底图与覆盖层可能有海岸线/边界差异，街区级缩放逐渐淡出；不作逆地理归属判定。自定义地点所属地区仍由用户指定。
- 改名和点亮功能不代表中国地图内容/边界/审图及商业发布要求已核实。旧静态图审图号仍不适用于精细底图；原有依赖安全与真机验证限制不变。

## 验证入口

- `npm test`：包括精确改名、不误改海峡/城市、34地区覆盖、手动点亮取消、当前旅行筛选、Vue响应式数据的结构化克隆、零长度线保护。
- `npm run test:map-fixes`：真实 MapLibre/Worker 专项。独立 Vite 测试入口 `tests/map-harness.html`，不进入生产构建；检查实际 GeoJSON 数据源、地图点击、快速开关、重排/筛选及导出缓存，不仅检查界面文字。
- `npm run test:travel`：实际 production 应用，新增真实界面连线开关、手动地区取消/重新点亮回归。
- 其他测试与未验证项见本版实测报告。上述浏览器测试需要可用的 OpenFreeMap 网络，另有完全阻断底图服务的失败回退专项。
