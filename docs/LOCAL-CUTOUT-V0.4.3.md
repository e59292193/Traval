# 本地异形冰箱贴 V0.4.3（H5 试用）

## 目标

不把“照片加相框”当作异形冰箱贴。新上传从原图提取透明主体，用纯代码简化画面，再沿实际蒙版轮廓加奶油白边和轻微阴影。放入原有手账冰箱贴区域，不改变旅行地点或统计。

**所有照片像素和编辑指令只在本机处理。不上传照片、不调用图像 API、不下载 AI 模型、不引入运行时依赖。** 地图仍会请求之前已有的 OpenFreeMap 瓦片/字体，不能把整个应用宣传为完全无网络。

## 使用步骤

1. 在预览下点击“制作照片冰箱贴 ↓” → 上传 JPEG / PNG / WebP。
2. 默认尝试“自动去背景”。此功能是按角落颜色移除边缘连通像素，不识别“人物”“建筑”；颜色相近会误删。
3. 复杂背景建议直接“圈出主体”：沿轮廓逐点点击，至少 3 点，点击“完成圈选”。支持最多 128 点；可撤回点或取消圈选。
4. 用“擦除”拖动去掉多余区域，用“补回”恢复误删区域。可调笔刷大小；支持最近 15 次编辑撤销。“点选背景”移除所点位置的颜色相近连通区域。
5. 不便在图上操作时，展开“坐标辅助操作”，输入图像横纵百分比添加圈选点、背景点或笔刷落点。竖图编辑画布高度不超过 360 CSS 像素。
6. 调整去背景容差、轻卡通化强度、轮廓白边宽度 → “生成异形冰箱贴”。棋盘格只是透明预览底，不在输出 PNG 中。
7. 检查结果 → “加入冰箱贴区域”。修改参数后必须重新生成，不能把旧预览误加入。
8. 已加入的贴可排序、移除或调整。调整从保留的原图和编辑配方继续；取消不会覆盖旧效果。H5 手动保存草稿可保留原图、配方和透明结果，刷新后通过“恢复草稿”恢复。

## 实际效果边界

- 卡通化：两轮保边平滑、颜色量化/简化、轻微饱和度调整与边缘压暗。强度为 0 保留原始颜色。
- 白边：按蒙版近似距离场向外扩展，不套方形、圆形，也不为未抠图的整张照片假造相框。
- 全图几乎未分离背景（保留 >98.5% 像素）或主体为空时阻止生成，提示圈选/擦除/补回。
- **不会自动理解主体，不会补画缺失建筑，不会把照片重绘成水彩插画。** 复杂背景、透明玻璃、头发、树枝、阴影需要人工修边；效果不能承诺与参考图一比一相同。
- 工作图片最长边缩至 768 像素，输出按主体裁去多余透明区域并留白边/阴影空间；不是高清实物印刷文件。原图保留供重新编辑，但算法处理仍用 768 像素画布。

## 数据与安全限制

- `Magnet.style = cutout`，包含不同的 `sourceAssetId`（原图）和 `assetId`（透明处理结果），以及有版本的 `cutout` 配方。
- 配方保存模式、容差、卡通强度、白边、多边形点、背景点和笔画；校验数量、坐标及数值范围。最多 100 笔、16000 个笔画点，每笔最多 2048 点，背景点击最多 32 个。
- 原图和输出分别引用；取消未加入内容、移除贴、重新生成替换旧结果时，无其他引用的图片会释放。每枚通常占 2 张源图；与照片/旅行历史共用 32 张上限，上传前预留两个位置。
- 冰箱贴引用的所有图片用 PNG 编码进 IndexedDB，避免恢复时透明背景变白。其他照片保留原 JPEG 保存方式。PNG 较大，草稿图片编码合计仍不得超过 30 MB；超限不覆盖已有草稿。
- 保留最多 8 枚的区域容量和旧版陶瓷方贴/圆形贴读取、调整、导出；旧作品可选择用原图重新制作异形。旧作品不会被静默重绘。
- Worker 在组件关闭时终止；处理超时（15 秒）、初始化失败会显示错误并允许重试，不偷偷回退到矩形照片。
- 本功能只在 H5 提供。小程序保留旧版照片贴/Canvas 输出；构建通过不代表小程序真机通过。

本次演示山景来自仓库原有 AI 示例场景，用手动多边形圈选生成；没有为结果另外调用生成模型。测试中的简单几何屋形和竖条只是自动背景移除/布局的技术夹具，不是作为设计成果提供的插画。
