# V0.4.4 · 省域轮廓手账

## 改动

- 默认未开启足迹合成时，保留原有水彩中国地图与照片拼贴。
- 海报不再截取 MapLibre 视窗或覆盖矩形底图。改用仓库现有 `region-overlay-wgs84.json` 行政区轮廓，在本地 Canvas 2D 生成透明背景地图：奶油纸描边、淡色填充、轻纸纹、地点图钉和虚线顺序连线。
- 默认“自动”范围：当前筛选内已核验的 WGS84 地点仅涉及一个省级行政区时，显示该地区完整轮廓（包括单个地点、同坐标和离岛）；涉及多个地区或没有有效地点时显示全国。直辖市、自治区和特别行政区同样按省级区域处理。旧坐标待核验记录不参与判断或绘点。自定义地点的所属地区由用户填写，不做逆地理编码核验。
- 范围按“全部旅行”或具体旅行筛选计算；“始终显示全国”可以覆盖自动判断。手动点亮其他地区不会把单省旅行切成全国，但全国模式仍保留这些高亮。
- “地图与手账配色”中的鼠尾草、落日陶土、海盐蓝会同步改变海报地图的填色、轮廓、图钉、路线和文字。水彩背景图仍保持原样。
- 移除冰箱贴制作/效果预览入口、海报中的冰箱贴菜单与展示效果；原展示区改为“旅途拾光”文字卡片。历史草稿的磁贴数据与源图继续兼容读取和保留，但本版本不显示或编辑它们，避免静默销毁旧数据。旧组件和纯逻辑测试保留供兼容回归，不作为本版本的公开入口。
- 精细交互地图仍在下方供选点、缩放和查看城市道路。其瓦片和字体需要联网，**海报轮廓生成与导出不再依赖远程地图加载**。H5 首次加载应用本身仍需网络，未新增 PWA/离线安装能力。

## 操作

1. 新建旅行并添加一个地点（例如天水），海报自动使用完整甘肃省轮廓。
2. 添加同省其他地点，范围仍为完整甘肃；添加其他省份地点后切为全国。
3. 在“地图与手账配色”中切换三套主题。
4. 在“海报地图范围”中选择“始终显示全国”可固定全国图。
5. 导出 JPEG 的构图与预览一致，支持原有两档清晰度。

## 数据与限制

继续使用仓库已有的 WGS84 概览行政区数据，不是新增的已审核/授权商业底图，也不是精确行政界线。全国轮廓不能视为经过审图的标准地图，现有数据对海岛、海域和细部的完整性仍需发布前单独审查；不得沿用旧静态图的审图号。轮廓路径采用 Mercator 投影，不拉伸各省。地点坐标源及互动地图来源与许可见 `TRAVEL-V0.4.md`、`FIXES-V0.4.1.md`。密集地点标签会避让或省略，所有记录仍保留在时间线，路线仅表示记录顺序。

互动足迹与自动省图目前仍是 H5 功能；微信小程序保持原静态图模式（同步移除冰箱贴入口/展示），构建通过不代表真机验证通过。
