# 架构说明

## 最小纵向闭环

本地选图 → 文件头与容量校验 → 平台解码与降采样 → 作品绑定照片 ID → 纯逻辑计算裁剪 → Canvas 预览 → 同一个渲染器按导出比例绘制 → JPEG → 本地下载/保存。

## 模块职责

| 路径 | 职责 |
| --- | --- |
| `src/types` | JSON 兼容模板、作品模型；结构化绘图接口和平台接口 |
| `src/templates/journey.ts` | 唯一模板、四个固定照片槽位、三套配色、确定图层顺序 |
| `src/core/crop.ts` | cover 裁剪、归一化位置、缩放、边界、拖动映射 |
| `src/core/text.ts` | 用户可感知字符、字数限制、中文/英文断行、最小字号及省略 |
| `src/core/image-header.ts` | JPEG/PNG/WebP 尺寸与部分 EXIF 信息；H5 解码前拒绝大图 |
| `src/core/work.ts` | 配置校验、作品初始化 |
| `src/render/poster.ts` | 逻辑坐标绘制；纸纹、相框、胶带、装饰均为程序化原创建形 |
| `src/platform/h5.ts` | 唯一使用 DOM/浏览器对象的底层适配；文件选择、Bitmap、画布、下载、指针、URL 回收 |
| `src/platform/weixin.ts` | 微信 Canvas 2D 节点、选图、临时文件、导出、相册保存 |
| `src/platform/index.ts` | uni 条件编译选择平台；不会把浏览器实现混入小程序运行包 |
| `src/components/RangeControl.vue` | 可触控的滑杆控件 |
| `src/pages/index/index.vue` | 页面状态、表单、槽位操作、确认、可恢复错误 |
| `tests/` | 核心测试与真实浏览器闭环测试 |

`core/` 不依赖 `window`、`document`、`localStorage`、浏览器图片类型或下载 API。绘图接口不绑定 HTMLCanvasElement。DOM 不参与模板布局或裁剪计算。没有 html2canvas、HTML 截图导出或通用设计器引擎。

## 模板与作品分离

- 模板：ID、版本、逻辑尺寸、预览配置、配色、有序图层。
- 作品：数据版本、模板 ID/版本、文字、配色 ID、四个槽位的照片素材 ID 与归一化裁剪参数。
- 照片资源：独立内存 Map，持有平台原生解码对象、尺寸、缩略图和销毁函数。原生对象、临时路径和 object URL 不进入模板。
- 作品可 JSON 序列化，但当前不提供草稿保存；没有把多张 Base64 写进 localStorage。

## 渲染与裁剪

逻辑画布为 1000 × 1340；预览栅格为 900 × 1206，响应式缩放显示；导出为 1500 × 2010 或 1000 × 1340。预览只在下一帧合并更新，不在每次输入时导出高清图片。

裁剪采用 cover 基础比例乘以 1–3 倍缩放。位置用 0–1 表示剩余源图范围内的偏移，计算 source rectangle 后传给 drawImage。拖动根据预览到逻辑坐标的比例转换，再按相框反向旋转，将位移映射到照片坐标；所有边界夹紧，避免露白。

预览/导出共用文字测量、换行、裁剪与图层顺序。渲染首先填充纸色，JPEG 不依赖透明背景。照片与旋转相框在同一个变换栈下裁切。导出画布不是页面截图，不带按钮或选中边框。

## 异步、内存和错误

选图全局串行：处理期间禁用选图、移除、重置和导出，避免多个大图同时解码。附加请求版本与页面存活检查，防止页面销毁后的旧结果写入状态。替换先成功解码新图，再释放旧图，失败不丢原照片。

H5 校验文件大小与头部像素后，使用 createImageBitmap 从原图方向解码，并请求降采样；不再对解码结果手动旋转。旧浏览器回退为 Image + 临时 Canvas 降采样。图片资源缓存到替换/删除/退出为止，不反复解码。释放 Bitmap、缩略图 URL、临时导出 URL、指针监听与绘图帧；临时导出画布使用后缩到 1 × 1。

结果弹层关闭后释放导出 URL；用户需要先保存再关闭。导出期间使用独立临时绘图目标，按钮锁定，异常恢复后保留原作品。

## 设计取舍

- 本阶段不做图片后台上传、在线地图服务、旅行统计、登录和付费。静态地图由本地素材解析器提供。
- 使用本地嵌入的 Caveat 拉丁字体，中文回退系统字体；无远程字体请求，跨设备字形差异仍需验证。
- 只实现当前模板所需图层；image 图层已保留稳定资产 ID 入口，但首版不使用外部图片装饰，未来新增素材需要配套解析/预加载注册，不应直接放 URL。
- 作品输入字数通过 grapheme 分割控制，不用原生 maxlength 粗暴截断 emoji；原生 input 限长回写需要经过 uni-input 的异步同步。
