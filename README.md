# 沿途 · Traval — 本地异形冰箱贴与旅行手账 V0.4.3

一个可实际编辑和导出图片的旅行手账海报 **H5 原型**。采用 uni-app / Vue 3 / TypeScript / Canvas 2D；不是静态效果图，也不是可直接商用上线的完整产品。

## V0.4.3 本地异形冰箱贴（H5 试用）

新上传默认采用 **主体抠图 → 轻卡通化 → 沿轮廓白边 → 透明 PNG → 加入手账**，不再默认创建方形或圆形相框。纯 Canvas / TypeScript / Web Worker，没有模型下载、上传接口或新增依赖。简单背景可按颜色自动去除；复杂照片需要手动圈选和擦除/补回。支持撤销、坐标辅助、容差/卡通强度/白边调节、原图保留和重新编辑；草稿用 PNG 保留透明度。**不是语义识别、AI 插画重绘，也不承诺一比一复制参考画风。** 详见 [使用步骤与限制](docs/LOCAL-CUTOUT-V0.4.3.md)。

## V0.4.2 照片冰箱贴（历史实现）

上传图片 → 选择奶油方贴/圆形徽章 → 调整构图 → 加入“我的冰箱贴”区域。支持最多 8 枚、调整/排序/移除、随手账导出和 H5 本地草稿恢复。全部照片处理在本机进行；本版保留图片背景，是白边和立体质感效果，不是 AI 抠图/重绘。详见 [操作与兼容说明](docs/MAGNETS-V0.4.2.md)。

## V0.4.1 修复

已统一“台湾省”地图标注，补上地区填色与地图点击点亮，修复 Worker 更新等待、快速连线开关/排序/筛选和导出地区缓存。详见 [修复与操作说明](docs/FIXES-V0.4.1.md)。

## V0.4：精细地图与旅行记录（H5）

保留水彩手账样式及静态地图回退，支持：

- **交互地图**：MapLibre GL JS + OpenFreeMap 远程矢量底图，可逐级查看城市与道路；缩放、拖动、聚合展开、查看旅行、全国概览和地图选点。地区可在地图和下方列表点亮；浅色覆盖用于概览，不是精确行政界线。
- **真实足迹**：317 个 GeoNames WGS84 城市/地点预设，或地图选点/手动 WGS84 自定义地点；填写到访日期和札记，从四个当前槽位选择照片并保留其版本。
- **多次旅行**：创建/编辑/删除旅行，添加/编辑/删除地点，上下调整地点顺序；按全部旅行或某次旅行查看地图；可一键将本次旅行的前四张已关联照片及名称/札记/日期载入手账。
- **路线与统计**：每次旅行内部按列表顺序连线，不跨旅行连接；按地点 ID 去重计算城市/地点数，合并手动标记和记录地区统计省级地区。空旅行计入旅行数，不代表已出行。
- **本地草稿**：手动保存整个手账、旅行记录和照片到 IndexedDB，刷新后可点“恢复草稿”；保存失败和不兼容草稿不覆盖当前作品。删除持久化草稿不会清空正在编辑的内容。
- **统一导出**：开启“足迹地图合成到海报”后，按当前旅行或全国范围绘制精细地图，保留水彩背景、最近回忆和贴纸。地图主区不叠加装饰照片以免遮挡足迹；照片仍在下方展示。关闭开关恢复原静态拼贴。

仍支持四张本地 JPEG/PNG/WebP 照片的独立缩放、平移、裁剪、三套配色与 1500×2010 / 1000×1340 JPEG。不是 html2canvas 或页面截图导出。

**此版本是 H5 原型，不是已获授权/审图的商业地图产品。** 动态数据来源、许可、坐标核验与发布阻塞见 [V0.4 地图与草稿说明](docs/TRAVEL-V0.4.md)。渲染引擎的开源许可不代替地图数据授权；原静态图片的审图号不能用于新交互地图。

不含登录、支付、道路导航、在线地理编码、实时 GPS、云端同步、运行时 AI 或统计 SDK。示例照片不会自动生成旅行记录。**草稿是手动保存，不是自动保存；未保存编辑刷新会丢失；清理浏览器数据也会删除草稿。** 地点预设不覆盖所有城市；自定义点未实现 GPS/GCJ-02/BD-09 转换，不能声称测绘精度定位。

微信小程序仍为原静态地图 Canvas 验证版，构建可用；**互动足迹与 IndexedDB 草稿只在 H5 实现**，需后续选择小程序地图方案和文件存储适配，并做真机测试。

## 第一次运行（不需要写代码）

1. 安装 Node.js（建议 Node 22 LTS 或 24 LTS；本次实际使用 24.22.1）。
2. 下载本仓库 ZIP 并解压，或使用下方 git 命令。
3. 在项目文件夹打开终端，依次执行：

```bash
git clone https://github.com/e59292193/Traval.git
cd Traval
npm ci
npm run dev:h5
```

若使用 ZIP 下载，无需执行前两行，直接在解压后的目录执行 `npm ci` 和 `npm run dev:h5`。终端出现 `Local` 地址后，在电脑浏览器打开它（通常是 `http://localhost:5173`；以终端实际显示为准）。不需要 API Key，不需要设置支付或数据库。

> 开发服务器仅用于本地开发。不要把它直接暴露到公网。这里没有进行外部部署或开启 GitHub Pages。

### 使用方法

1. 在手账编辑器选择自己的照片，修改文字和配色；可选“体验示例作品”，但 AI 示例不代表真实旅行。
2. 点预览下方“编辑足迹地图与旅行记录 ↓”，或下滚至“旅行足迹”。
3. 输入旅行名称 → “新建旅行” → 选择城市 → 填写日期、札记 → “添加地点”。
4. 可从当前照片槽位选取照片，添加时保留照片版本。示例照片不能新关联为真实足迹照片。后续替换或清空手账槽位，不会改写已关联的历史照片；解除关联/删除记录后，无其他引用的照片才释放。
5. 可点“将本次旅行载入手账”，把前四张关联照片和名称/札记/日期放入海报；使用上移/下移调整路线顺序；地图范围可切换全部或某次旅行；地区列表可手动标记去过的地区。有真实记录的地区不能仅靠取消手动标记清除高亮。
6. 点“保存本地草稿”。刷新后不会自动覆盖空白编辑器；点“恢复草稿”并确认，即可恢复保存内容。
7. 开启“足迹地图合成到海报”后回到预览导出，或者关闭开关沿用静态拼贴。导出范围由“海报地图范围”选择当前旅行或全国，不沿用互动地图临时视窗；当前旅行筛选仍有效，海报注明筛选名称，统计为全部记录。
8. 桌面下载；移动端可长按结果图片保存。真实 iOS/Android/微信环境仍待验证。

## 构建与测试

```bash
npm test                  # 纯逻辑自动化测试
npm run typecheck          # Vue + TypeScript
npm run build:h5           # dist/build/h5
npm run build:mp-weixin    # dist/build/mp-weixin；构建不代表真机通过
```

浏览器端到端测试（先构建，再在一个终端启动静态服务）：

```bash
npm run build:h5
# 如果有 Python 3：
python3 -m http.server 4180 --directory dist/build/h5
```

另开终端：

```bash
npx playwright install chromium
npm run test:e2e       # 原有照片编辑/异常回归
npm run test:travel    # 旅行地图/草稿/导出闭环
npm run test:map       # V0.3 草稿迁移/单点/网络失败与静态回退
npm run test:cutout
npm run test:magnets # 旧版相框草稿兼容测试
npm run test:map-fixes # 真实图层点亮、连线与标注修复专项
```

也可用任意静态服务器提供 `dist/build/h5`，默认测试地址为 `http://127.0.0.1:4180`。通过环境变量 `BASE_URL` 指向其他本地端口；系统已有 Chromium 时可设置 `CHROMIUM_PATH`。测试会在 `artifacts/` 生成合成测试图片、截图、JPEG 和 JSON 报告（不包含用户照片，不提交到仓库）。测试用例会启动本地无头浏览器，沙箱环境使用 `--no-sandbox`，不是网站运行配置。

## 已知边界与发布阻塞项

- 当前是 **H5 原型**。微信小程序已有独立 Canvas 节点适配与构建，但无微信开发者工具/真机运行证据。需要填写自己的 AppID，并完成照片方向、字体、相册权限等验证。
- 拉丁手写标题使用本地 Caveat 字体子集（SIL OFL 1.1，许可随仓库提供）；中文和缺字回退系统字体，不同设备字形会有差异。
- H5 单张最多 15 MB、4000 万像素、单边 16000 像素；解码后最长边降采样至 2400。小程序验证版保守限制单边 4096，不承诺高像素手机原图都可直接使用。
- 桌面 Chromium 已测试；Safari、iOS、Android 和微信内置浏览器保存、EXIF 全方向、系统内存上限仍需真机验证。
- 依赖安全审计仍有高风险提示，详见 [安全说明](docs/SECURITY.md)。**完成依赖升级评估及复测前，不应直接作为商业发布版上线。**
- 精细地图会请求远程 OpenFreeMap 瓦片/字体，不读取 GPS、不上传照片或旅行文字。公开发布仍需核实中国地图内容、署名与许可；旧静态图审图号不适用于新底图。
