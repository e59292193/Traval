# 沿途 · Traval

一个可实际编辑和导出图片的旅行手账海报 **H5 原型**。采用 uni-app / Vue 3 / TypeScript / Canvas 2D；不是静态效果图，也不是可直接商用上线的完整产品。

## 你可以做什么

- 为一个原创「单次旅行纪念」模板选择 4 张本地照片。
- 替换、移除照片；对每个槽位分别缩放、水平/垂直平移；选定裁剪后可以拖动预览。
- 编辑标题（24 个用户可感知字符）、副标题（40 个）、日期文本（30 个）。日期默认留空。
- 切换鼠尾草 / 落日陶土 / 海盐蓝三套配色。
- 实时预览，导出 1500 × 2100 或 1000 × 1400 的 JPEG。
- 重置前确认；空槽位导出前确认；出错后保留作品。

不含登录、支付、云端相册、统计 SDK、AI 调用、真实地图或自由画布。没有内置示例照片，不会把别人的照片冒充用户作品。**刷新或离开页面会丢失作品**，没有草稿持久化或跨设备同步。

## 第一次运行（不需要写代码）

1. 安装 Node.js（建议 Node 22 LTS 或 24 LTS；本次实际使用 24.22.1）。
2. 下载本仓库 ZIP 并解压，或使用下方 git 命令。
3. 在项目文件夹打开终端，依次执行：

```bash
git clone https://github.com/e59292193/Traval.git
cd Traval
npm ci
npm run dev:h5
```

若使用 ZIP 下载，无需执行前两行，直接在解压后的目录执行 `npm ci` 和 `npm run dev:h5`。终端出现 `Local` 地址后，在电脑浏览器打开它（通常是 `http://localhost:5173`；以终端实际显示为准）。不需要 API Key，不需要设置支付或数据库。

> 开发服务器仅用于本地开发。不要把它直接暴露到公网。这里没有进行外部部署或开启 GitHub Pages。

### 使用方法

1. 点击四个「添加照片」按钮，依次选图。
2. 点击某张照片下的「裁剪」，调整缩放与位置；也可在左侧预览拖动该照片。
3. 修改标题、目的地和日期，选配色。
4. 点击「导出我的旅行手账」，检查弹出的图片，再点击「保存图片」。
5. 桌面浏览器发起下载；手机 / 微信内浏览器可以在弹出的图片上长按保存。不同手机的保存限制仍需真机验证。

手机窄屏先显示预览，再显示编辑控件；裁剪面板的滑杆不依赖 hover 或精确拖动。

## 构建与测试

```bash
npm test                  # 纯逻辑自动化测试
npm run typecheck          # Vue + TypeScript
npm run build:h5           # dist/build/h5
npm run build:mp-weixin    # dist/build/mp-weixin；构建不代表真机通过
```

浏览器端到端测试（先构建，再在一个终端启动静态服务）：

```bash
npm run build:h5
# 如果有 Python 3：
python3 -m http.server 4173 --directory dist/build/h5
```

另开终端：

```bash
npx playwright install chromium
npm run test:e2e
```

也可用任意静态服务器提供 `dist/build/h5`，默认测试地址为 `http://127.0.0.1:4173`。通过环境变量 `BASE_URL` 指向其他本地端口；系统已有 Chromium 时可设置 `CHROMIUM_PATH`。测试会在 `artifacts/` 生成合成测试图片、截图、JPEG 和 JSON 报告（不包含用户照片，不提交到仓库）。测试用例会启动本地无头浏览器，沙箱环境使用 `--no-sandbox`，不是网站运行配置。

## 已知边界与发布阻塞项

- 当前是 **H5 原型**。微信小程序已有独立 Canvas 节点适配与构建，但无微信开发者工具/真机运行证据。需要填写自己的 AppID，并完成照片方向、字体、相册权限等验证。
- 系统字体在不同设备上的具体字形会不同；没有下载或打包第三方字体。
- H5 单张最多 15 MB、4000 万像素、单边 16000 像素；解码后最长边降采样至 2400。小程序验证版保守限制单边 4096，不承诺高像素手机原图都可直接使用。
- 桌面 Chromium 已测试；Safari、iOS、Android 和微信内置浏览器保存、EXIF 全方向、系统内存上限仍需真机验证。
- 依赖安全审计仍有高风险提示，详见 [安全说明](docs/SECURITY.md)。**完成依赖升级评估及复测前，不应直接作为商业发布版上线。**
- 没有加入地图 API。需求正文明确首版不放真实地图，因此将结尾的「开源地图 API」解释为后续地图模板的选项；将来仍需单独核实底图许可、审图要求和坐标规则。
